
# Sales Data Analysis with Python
Sales data analysis using Python and Pandas, including revenue analysis, product performance, and data visualization.

## Project Overview
This project analyzes sales transaction data using Python to understand product performance, revenue, and sales volume.

## Dataset
The dataset contains 5 sales transactions involving 3 products:
- Mouse
- Keyboard
- Monitor

The dataset includes transaction dates, product names, quantities, and unit prices.

## Tools
- Python
- Pandas
- Matplotlib
- Google Colab

## Analysis
- Total revenue by product
- Total units sold by product
- Average transaction value
- Number of transactions per product
- Sales summary

## Key Findings
- Mouse has the highest sales volume, with 5 units sold.
- Monitor generates the highest revenue, totaling Rp1,500,000.
- Keyboard generates Rp750,000 in revenue.
- Mouse generates Rp500,000 in revenue.

## Recommendations
- Increase Mouse sales through promotional campaigns.
- Offer Mouse and Keyboard bundle packages.
- Maintain Monitor sales performance.
- Evaluate promotions using future sales data.

## Conclusion
The analysis shows that sales volume and revenue provide different perspectives on product performance. Analyzing both metrics helps identify products that sell frequently and products that contribute the most revenue.
